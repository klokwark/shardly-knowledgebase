# Create your account

You can sign up with an email address, with Google, or with Discord. All three
produce the same account — the difference is only how you prove it is you.

## With an email address

1. Go to the sign-up page.
2. Enter your name, email address and a password of at least 10 characters.
3. We send a six-digit code to that address. Enter it.

The code expires. If it has been sitting in your inbox for a while, ask for a
new one rather than typing the old one.

## With Google or Discord

Press the button, approve the request, and you are in. There is no password to
set — and no password to lose.

If you later want a password as well, you can add one from
**Account → Security**.

## Which should you pick?

It genuinely does not matter much. Two things worth knowing:

- **Signing in with Discord does not let us send you Discord DMs.** Those are
  two different applications, for a reason. If you want notifications in
  Discord, connect it separately from
  [Account → Notifications](../account/link-discord-for-dms.md).
- **An email account can add a passkey** and stop typing a password
  altogether. See [passkeys](../account/passkeys.md).

## The verification email did not arrive

- Check spam. Our mail comes from a shardly.xyz address.
- Wait a minute. There is a short cooldown between sends, so pressing the
  button repeatedly does not send more mail.
- If it still has not arrived after ten minutes, the address may have a typo
  in it. Start again with the address written out carefully.

## Still stuck?

Ask in [our Discord](https://discord.gg/shardly). You cannot open a ticket
without an account, which is exactly the problem you are having.
