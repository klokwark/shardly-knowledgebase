# What is not available yet

We would rather tell you plainly than have you find out after paying.

Some of these are mentioned on our marketing pages. If you have read something
on the site that is contradicted here, **this page is the accurate one** and
we are fixing the site.

## Not built yet

| | Status |
| --- | --- |
| **`your-bot.shardly.xyz` subdomains** | Not built. Mentioned on the site; it should not be. |
| **Custom domains** | Not built. |
| **Automatic crash and downtime DMs** | Not built. We restart your bot, but we do not yet message you when it happens. |
| **Measured uptime on the status page** | Not built. The status page has no live feed yet. |
| **Resource alerts** (CPU, memory, disk thresholds) | Not built. |
| **Scheduled tasks and cron jobs** | Not built. |
| **SFTP** | Not built. Use the file manager or GitHub import. |
| **Log search and retention** | Not built. The console is live output only. |
| **Public API and API keys** | Not built. |
| **Outgoing webhooks** | Not built. |
| **Deploy on push** | Not built. Imports are manual. |
| **Teams — several people on one account** | Not built. One account, one owner. |
| **Single sign-on** | Not built. |
| **VAT ID and purchase orders in the dashboard** | Not built. Ask support and we will do it by hand. |
| **In-place plan upgrades** | Not built. Buy the new plan and move across, or ask us to move it for you. |
| **Shardly Studio (website hosting)** | Announced for December 2026. Not open. |

## Partly there

- **Backups** can be created and restored. Download and retention management
  are thinner than we would like.
- **Add-on shards** apply to your most recently created server. If you have
  several, tell us which one you meant.
- **Discord.py and other runtimes** are shown as sold out, which is literal.
  Discord.js is what you can buy today.

## Why tell you this?

Because the alternative is you buying on the strength of a feature list and
finding out later. A support reply that repeats a marketing claim we have not
built turns a disappointment into being lied to, and that is a much worse
thing to have done.

If one of these is a blocker for you, say so in a ticket or in Discord. It
genuinely affects what we build next, and we will tell you honestly whether it
is weeks or months away rather than say "soon".
