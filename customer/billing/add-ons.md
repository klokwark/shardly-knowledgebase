# Add-ons

Extras bought on top of a plan, billed on the same cycle.

## Extra shards

**€5 a week for five shards.** Bought from **Add-ons** in the dashboard.

They are added to the server you most recently created. If you run several
servers and want them on a specific one, open a ticket and say which — there
is not yet a picker in the UI for this.

### Do you need more shards?

One shard handles roughly 2,000 Discord servers. Discord requires sharding
past that; below it, more shards will not make your bot faster and will use
more memory.

If your bot is slow and it is in 300 servers, the problem is not shards. Open
a ticket and we will look.

## Database

**A 5 GB database alongside your bot.** Bought from the same screen.

For a bot that needs to remember things between restarts and has outgrown a
JSON file.

## Cancelling an add-on

Through **Manage billing**, like any subscription. Shards are removed from the
server at the end of the paid period.
