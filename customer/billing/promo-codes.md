# Discount codes

## Using one

Enter it at checkout, in the field on Polar's payment page. Not afterwards.

## After the fact

A code cannot be applied to a subscription that already exists. The discount
is part of how the subscription was created, so adding it later means
cancelling and buying again.

If you bought minutes ago and missed the field, open a ticket quickly — that
is the one case where redoing it is straightforward.

## Launch code

There is a 10% code for your first monthly billing cycle, shown on the pricing
page. First cycle only, monthly only.

## Redeem links

Separate from discount codes. A redeem link grants a plan outright — usually
from a giveaway, a partnership, or support making something right.

Open the link while signed in and it applies to your account. They are single
use and they expire.

## A code that will not work

Check in this order:

- It has expired.
- It has already been used, if it was single-use.
- It is for a cycle you are not buying — a monthly-only code on a weekly
  checkout.
- It is a redeem link, not a checkout code. Those go to `/redeem/...`, not
  into the payment form.

## Still stuck?

[Open a billing ticket](https://shardly.xyz/app/support/new) with the code and
where you got it.
