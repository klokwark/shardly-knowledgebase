# How you sign in

Five ways, and you can have several at once on the same account.

| Method | Set up from | Notes |
| --- | --- | --- |
| Password | Account → Security | At least 10 characters |
| Google | Sign-in page | No password needed |
| Discord | Sign-in page | Does **not** enable Discord DMs |
| Passkey | Account → Security | Face, fingerprint or security key |
| Sign-in link | Sign-in page | Emailed, single use |

## Adding a second method

Sign in with what you have, then add the other from **Account → Security**.
Two methods is a good idea: it is the difference between losing a phone and
losing an account.

## Sign-in links

Enter your address and we email a link. It works once and expires.

There are limits — a minute between sends, and five an hour to one address —
because otherwise the form is a way to send mail to strangers.

If a link says it is invalid, it has almost always already been used, often by
an email client that fetched it to generate a preview. Ask for another.

## Changing your password

**Account → Security → Change password.** You need the current one.

Changing it signs out every other session. That is deliberate: the usual
reason to change a password is that somebody else might have it.

## Forgotten password

Use **Forgot password** on the sign-in page. The reset link goes to your
address and, like a password change, ends every session on the account when
you use it.

If you cannot receive mail at that address any more, see
[I cannot sign in](../troubleshooting/cant-sign-in.md).

## Still stuck?

Ask in [our Discord](https://discord.gg/shardly) — if you cannot sign in, you
cannot open a ticket. Support will never ask for your password there, or
anywhere.
