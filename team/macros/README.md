# Macros

Starting points, not scripts.

## How to use them

**Always edit before sending.** A macro pasted verbatim reads like a macro,
and customers can tell. Change the name, cut what does not apply, add the one
specific detail about their situation.

The macro saves you the structure. You supply the substance.

## The six in the product

The staff panel has six built in, which cover the most common shapes:
acknowledge, ask for logs, token reset, point at billing, restarted for you,
and a closing note.

The files here are longer and cover more ground. If you find yourself pasting
one of these repeatedly, say so — it may belong in the product list, where it
is one click instead of a tab switch.

## The rules

- Use their name.
- Sign with yours.
- Cut anything that does not apply to this ticket.
- Never send a macro that promises something we have not built.
